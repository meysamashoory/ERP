# سامانه برنامه‌ریزی و کنترل تولید (ERP)

وب‌اپلیکیشن برنامه‌ریزی و کنترل تولید برای یک کارخانه تولید اتصالات و لوله‌های
پلاستیکی، ساخته‌شده با **Python / Django**. سامانه روی یک سرور مرکزی مستقر می‌شود
و کاربران با سطوح دسترسی مختلف از طریق مرورگر (آدرس IP سرور) به آن دسترسی دارند.

> A production planning & control (ERP-style) web application built with Django.
> Persian (RTL) UI, Jalali (Shamsi) dates, role-based access, Excel/PDF reports.

## امکانات پیاده‌سازی‌شده

- **داشبورد تحلیلی**: شاخص‌های کلیدی تولید، انحراف، توقفات، موجودی و نمودارها.
- **ثبت تولید روزانه**:
  - اتصالات (واحد شمارش: عدد) با شماره دستگاه، سیکل یک‌ضرب، حفره فعال، ضایعات، مواد و توقفات.
  - لوله‌ها (واحد شمارش: شاخه/کلاف/متر) با فیلدهای متناسب با نوع محصول (پوش‌فیت/فاضلابی/آبرسانی/دریپردار/تیپ/خرطومی).
- **برنامه‌ریزی هفتگی تولید** با شماره برنامه، تاریخ شمسی، محاسبه خودکار روز هفته،
  منطق آبشاری «روز تعویض قالب → تاریخ»، ردیف‌های تکرارشونده تولید، و **گردش‌کار تأیید مدیر**.
- **هشدار سابقه دستگاه**: اگر دستگاهی در سوابق تولید نباشد، هشدار قرمز ثبت می‌شود (بدون توقف کار).
- **گزارش‌گیری با فیلتر** (واحد، بازه تاریخ شمسی، جستجو) و **خروجی Excel و PDF**.
- **مدیریت کاربران و ۴ سطح دسترسی** مطابق مشخصات.
- **فهرست‌های قابل ویرایش** (نوع تولید، دلایل توقف) از طریق پنل مدیریت.
- **تاریخ شمسی** در سراسر سامانه (django-jalali).

بخش‌هایی مانند طراح فرم چاپی، آپلود/نگاشت داده‌های اکسل به‌عنوان منابع داده، و
پشتیبان‌گیری/بازیابی تفکیکی در پنل مدیریت به‌عنوان گام‌های بعدی در نظر گرفته شده‌اند
(مدل داده و ساختار برای افزودن آن‌ها آماده است).

## سطوح دسترسی

| نقش | توضیح |
| --- | --- |
| مدیر برنامه‌ریزی | دسترسی کامل، مدیریت کاربران، تأیید برنامه‌ها، پشتیبان‌گیری |
| کارشناس برنامه‌ریزی | همه صفحات جز مدیریت کاربران؛ ثبت داده؛ برنامه هفتگی نیاز به تأیید مدیر دارد |
| کارمند برنامه‌ریزی | ثبت داده در همه بخش‌ها جز ایجاد برنامه هفتگی (فقط مشاهده) |
| مشاهده‌گر | فقط داشبورد و گزارش‌ها (فقط خواندن) |

## راه‌اندازی محلی

پیش‌نیاز: Python 3.12 و بسته سیستمی `python3.12-venv`.

```bash
bash scripts/install.sh          # ساخت venv، نصب وابستگی‌ها، مهاجرت‌ها، داده نمونه
source .venv/bin/activate
python manage.py runserver 0.0.0.0:8000
```

سپس مرورگر را روی `http://<server-ip>:8000/` باز کنید.

### حساب‌های نمونه (گذرواژه همه: `erp12345`)

| نام کاربری | نقش |
| --- | --- |
| `admin` | مدیر برنامه‌ریزی (superuser) |
| `expert` | کارشناس برنامه‌ریزی |
| `clerk` | کارمند برنامه‌ریزی |
| `viewer` | مشاهده‌گر |

## پیکربندی (متغیرهای محیطی)

| متغیر | پیش‌فرض |
| --- | --- |
| `DJANGO_SECRET_KEY` | کلید توسعه (در تولید تغییر دهید) |
| `DJANGO_DEBUG` | `True` |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1,0.0.0.0` |
| `DJANGO_TIME_ZONE` | `Asia/Tehran` |

پایگاه داده پیش‌فرض SQLite است (بدون نیاز به سرویس جانبی). برای تولید می‌توان به
PostgreSQL مهاجرت کرد.

## ساختار پروژه

```
erp/            # تنظیمات و URLها
accounts/       # کاربران، نقش‌ها، دسترسی‌ها
catalog/        # واحدها، دستگاه‌ها، گروه‌های محصول، فهرست‌های گزینه‌ای
production/     # ثبت تولید روزانه اتصالات و لوله‌ها + توقفات
planning/       # برنامه‌ریزی هفتگی + گردش‌کار تأیید
core/           # داشبورد، گزارش‌ها، خروجی Excel/PDF، seed
templates/      # قالب‌های RTL فارسی
static/         # CSS
scripts/        # install.sh / start.sh
```
